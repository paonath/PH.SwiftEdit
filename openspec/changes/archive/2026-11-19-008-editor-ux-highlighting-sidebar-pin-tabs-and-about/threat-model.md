# Threat Model: PH.SwiftEdit Editor UX, Highlighting, Percentage Sidebar, Tab Reordering & Help About

## 1. Asset Boundaries & Trust Zones
- **Trusted Core Engines (`SwiftEditCore`, `.macOS(.v26)` / `.iOS(.v26)`)**: Stateless pure value-type scanners (`BracketMatcher`, `BacktickHighlightScanner`, `MarkdownSmartNewlineEngine`), `WorkspaceTabSession`, and confined `DotfileFolderNavigator` (`[AR-001]`, `[AR-002]`, `[BC-001]`).
- **User-Authorized Workspace Sandbox (`FileSystemProviding`, `SecurityScopedResourceAccessing`)**: Directory trees mounted via macOS App Sandbox security-scoped bookmarks (`[SEC-001]`, `[SEC-002]`, `[SEC-003]`). Untrusted file contents (untrusted Markdown, minified single-line files, binary files, crafted filenames, hostile symlinks) cross into this zone during shallow listing, binary probing, and editing.
- **External Browser Handoff Boundary (`NSWorkspace.shared.open`)**: External links surfaced in `AboutSheetView` (GitHub repository URL and MIT License URL) cross out of the offline sandboxed app and must pass `https`-only host validation plus explicit user confirmation (`[SEC-004]`, `[UI-008]`).
- **Presentation Layer (`SwiftEditUI`, `@MainActor`)**: Non-mutating TextKit 2 rendering attributes (`SwiftEditNSTextView`), appearance selector, percentage-resized sidebar, tab strip, and interactive single-segment file/folder creation dialogs (`[AR-003]`, `[UI-005]`, `[UI-006]`).

## 2. STRIDE Threat Analysis

| Threat Category | Potential Vector | Security Requirement & Mitigation |
| :--- | :--- | :--- |
| Spoofing | Crafted external links in `AboutSheetView` (`javascript:`, `file:`, `http://`, homograph/hostless URIs) or spoofed filenames with Unicode BiDi override characters (`U+202E`, `U+2066`) in right-click Create File/Folder prompts. | Route both repository and MIT License links exclusively through `AboutSheetDescriptor.prepareExternalLinkConfirmation(rawURI:)` enforcing `https` with non-empty host and explicit user alert (`[SEC-004]`, `[UI-008]`). Enforce `SidebarItemNameValidator.validate(_:)` rejecting BiDi overrides, control chars, and separators (`[BC-012]`, `[SEC-012]`). |
| Tampering | Malicious symlinks inside a workspace folder redirecting `DotfileFolderNavigator`'s `8 KiB` binary probe or right-click Create File/Folder outside the granted scope; tab reorder attempts breaking pinned-first invariants or injecting binary tabs. | Execute `DotfileFolderNavigator.verifyConfinement` on `resolvingSymlinksInPath()` strictly BEFORE probing bytes or creating files/folders (`[SEC-002]`, `[SEC-003]`, `CWE-22`). Restrict `WorkspaceTabSession` reordering strictly within pinned/unpinned partitions and preserve binary tab exclusion (`[BC-008]`, `[DATA-003]`). |
| Repudiation | Silent unauthorized disk writes from empty-area right-click Create File/Folder or accidental binary file mutation via Enter/smart newline interception. | Require explicit modal single-segment name confirmation prior to invoking confined `FileSystemProviding.createFile`/`createDirectory`; block click-to-open on `isBinary == true` sidebar rows and short-circuit `MarkdownSmartNewlineEngine` on `isBinaryReadOnly` snapshots (`[DATA-003]`, `[SEC-012]`). |
| Information Disclosure | Reading arbitrary out-of-scope files via symlinked entries during sidebar binary classification or logging sensitive dotfile paths/contents during scanner errors. | Enforce symlink confinement prior to any `8 KiB` read, bracket access with `startAccessing`/`defer { stopAccessing }`, and emit only typed `DomainError` codes without logging dotfile content (`[SEC-002]`, `[SEC-003]`, `[SEC-006]`, `[SEC-011]`). |
| Denial of Service | Pathological single-line minified files (`> 4096` UTF-16 units), deeply nested unclosed brackets/backticks, or multi-gigabyte binary files in a folder causing UI hangs (`> 16 ms` keystroke budget) or OOM during shallow listing. | Enforce linear $O(n)$ single-pass scanners with zero backtracking regexes and strict `4096` UTF-16 line-length abort (`.degradedOrTimedOut`) in `BracketMatcher`, `BacktickHighlightScanner`, and `MarkdownSmartNewlineEngine` (`[BC-011]`, `[SEC-012]`, `[UI-012]`). Cap sidebar binary probes strictly at `DocumentCodec.binaryProbeBytes` (`8 KiB`) (`[DATA-003]`, `CWE-400`). |
| Elevation of Privilege | Escaping App Sandbox confinement via path traversal (`../`) in interactive right-click Create File/Folder prompts or launching external shells/schemes from About links. | Reject `.`, `..`, `/`, `:`, and symlink escapes via `SidebarItemNameValidator` and `FileSystemProviding` confinement; maintain 100% offline zero-subprocess execution with no new entitlements or SPM packages (`[AR-005]`, `[SEC-001]`, `[SEC-003]`, `[SEC-004]`). |

## 3. Abuse Cases & Negative Scenarios
- **Abuse Case 1 (`N2`, `N4` — Scanner Algorithmic DoS & Binary Guard)**: Supplying a `4097`-unit single line or a binary read-only snapshot to `BracketMatcher`, `BacktickHighlightScanner`, or `MarkdownSmartNewlineEngine` MUST degrade/return `nil` immediately without unbounded scanning or buffer mutation (`[BC-011]`, `[SEC-012]`).
- **Abuse Case 2 (`N6` — Symlink Escape on Sidebar Binary Probe)**: Placing a symlink pointing to `/etc/passwd` or an external binary inside a mounted folder MUST cause `DotfileFolderNavigator.listEntries` to throw `DomainError.securityScopeViolation` prior to reading any probe bytes, with balanced `startCount == stopCount` (`[SEC-002]`, `[SEC-003]`).
- **Abuse Case 3 (`N9` — Path Traversal & BiDi Spoofing in Right-Click Create Prompt)**: Entering `"../escape.md"`, `"sub/file.md"`, or `"notes\u{202E}gpj.md"` into the right-click Create File/Folder prompt MUST throw `DomainError.invalidItemName` with zero disk writes (`[BC-012]`, `[SEC-012]`).
- **Abuse Case 4 (`N10` — Tampered License/Repository URI in About Dialog)**: Passing `"http://github.com/..."`, `"javascript:alert(1)"`, or `"file:///LICENSE"` to `AboutSheetDescriptor.prepareExternalLinkConfirmation(rawURI:)` MUST return `nil` and prevent `NSWorkspace.shared.open` (`[SEC-004]`, `[UI-008]`).
